# **What Makes a Movie Successful?**
IMDb Movie Success Analysis | Power BI

### 📌 เกี่ยวกับโปรเจกต์
Dashboard นี้ตั้งคำถามว่า "หนังแบบไหนถึงประสบความสำเร็จ?" โดยเลือกวัดความสำเร็จจาก 2 มุม คือ เรตติ้ง (Rating) และ รายได้ (Revenue) แล้วเปรียบเทียบแยกตามแนวหนัง (Genre)

### 📂 ข้อมูล
- Dataset: https://www.kaggle.com/datasets/PromptCloudHQ/imdb-data
- ฟิลด์หลักที่ใช้: Title, Genre, Year, Rating, Revenue (ล้านดอลลาร์)
- หนังบางเรื่องไม่มีข้อมูลรายได้ จึงสร้าง KPI Revenue Coverage % เพื่อบอกว่ามีข้อมูลรายได้ครอบคลุมกี่ % (87.1%)

### 🛠️ ขั้นตอนการทำงาน
1. Data Cleaning (Power Query) ก่อนนำข้อมูลมาวิเคราะห์ ได้ทำความสะอาดข้อมูลให้ถูกต้องก่อน ดังนี้
   - แก้ encoding ของชื่อหนังและชื่อนักแสดงให้ถูกต้อง
   - ตรวจสอบพบค่าที่ผิดปกติในคอลัมน์ Revenue (Millions) แสดงค่า 0 จึงได้แปลงเป็นค่าว่าง
   - ตรวจสอบพบว่าคอลัมน์ Revenue (Millions) มีข้อมูลหายไป ~13% จึงเลือก ไม่เติมค่า (no imputation) เพราะการเติมด้วยค่าเฉลี่ยจะสร้างข้อมูลที่ไม่มีอยู่จริง
2. Data Modeling (Bridge Tables) คอลัมน์ Genre และ Actors เก็บหลายค่าในช่องเดียว เช่น Action,Adventure,Sci-Fi ถ้าวิเคราะห์ตรง ๆ จะนับแยกแนวไม่ได้ จึงแยกออกมาเป็น bridge table (MovieGenre, MovieActor) ทำให้หนัง 1 เรื่องถูกนับ 1 ครั้งในทุกแนวที่อยู่ โดยยอดรวมไม่ถูกนับซ้ำจนเกินจริง
3. DAX Measures มีดังนี้
   - Movies / Movie Count คำนวณจำนวนหนัง
   - Avg Rating คำนวณค่าเฉลี่ยเรตติ้ง
   - Median Revenue ใช้ Median แทน Average เพราะค่ารายได้หนังเบ้ขวาค่อนข้างมาก (หนังบล็อกบัสเตอร์ไม่กี่เรื่องดึงค่าเฉลี่ยขึ้น)
   - Revenue Coverage % คำนวณสัดส่วนหนังที่มีข้อมูลรายได้
4. Dashboard ประกอบด้วย
   - KPI Cards แสดงจำนวนหนัง ค่าเฉลี่ยเรตติ้ง ค่ากลางของรายได้ และสัดส่วนของหนังที่มีข้อมูลรายได้
   - Bar Chart แสดงจำนวนหนังแยกตาม Genre
   - Scatter Chart แสดงข้อมูล Median Revenue (แกน X) × Avg Rating (แกน Y) โดยให้ขนาดของจุดแสดงตามจำนวนหนัง
   - Slicers แสดงตัวกรองตาม Year และ Genre

### 💡 Insights
1. หนังแนว Drama มีจำนวนมากที่สุด แต่จำนวนมากไม่ได้แปลว่ามีรายได้มากตามไปด้วย — Median Revenue ของ Drama ต่ำกว่าหนังในหลาย ๆ แนว
2. หนังแนว Animation นำทั้งเรตติ้งและรายได้ — Median Revenue สูงสุด (~190ล้าน) และ Avg Rating สูงกว่า 7.3
3. หนังแนว Adventure และ Action ทำรายได้ดี แต่เรตติ้งอยู่ในระดับกลาง
4. หนังแนว War / Biography มีเรตติ้งสูง แต่รายได้ต่ำ — เป็นหนังที่ "คนชอบ" มากกว่า "ทำเงิน"
5. หนังแนว Horror มีเรตติ้งต่ำที่สุด (~6.1)
